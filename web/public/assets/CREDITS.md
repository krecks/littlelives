# Third-party assets

All of the third-party art below is **CC0 1.0 (public domain)**. You don't have to credit it, but we list it so it's easy to trace and replace.
Downloaded 2026-10-07. Textures were resized and re-encoded (JPG). Fabric, wood, foliage, grass and wall albedo maps were converted to greyscale "detail" maps, so the manifest colours set the hue.
